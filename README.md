# Snowpile Safe: сборки

Здесь лежат готовые сборки Snowpile Safe и `appcast.xml`, откуда установленные копии узнают об обновлениях.
Каждое обновление подписано ключом, без которого приложение его не примет.

## Установить

1. Скачать [Snowpile.dmg](https://github.com/djsasha127/snowpile-releases/releases/latest/download/Snowpile.dmg).
2. Открыть и перетащить Snowpile Safe в «Программы».
3. Запустить. Если macOS скажет, что не может проверить разработчика, открыть
   Системные настройки → Конфиденциальность и безопасность и внизу нажать «Открыть всё равно».

Дальше приложение раз в день проверяет обновления и спрашивает, ставить ли новую версию.
